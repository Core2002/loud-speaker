# loud-speaker

基于 Rust + [cpal] 的实时音频桥接工具：把**麦克风**采集到的声音经过内部缓冲后，直接送到**扬声器**播放，可当作一台简易的“实时扩音/喊话器”使用。

> 已适配不同的硬件：麦克风与扬声器的采样率、声道数不一致时（例如单声道麦克风 + 立体声扬声器，或 44.1kHz 与 48kHz 混搭），程序会自动做单声道归一、采样率重采样与声道扩展，避免拖音、变调、无声或延迟无限增大等问题。

[cpal]: https://github.com/RustAudio/cpal

## 工作原理

```
   麦克风(任意采样率/声道)        扬声器(任意采样率/声道)
        │                              ▲
        ▼                              │
  ┌───────────┐  单声道环形缓冲   ┌───────────┐
  │    mic    │ ──降混为 mono──▶ │  AudioBus │ ──重采样/升混──▶ 填满输出缓冲
  └───────────┘                  └───────────┘
```

- `mic`：输入设备按**自身默认格式**采集，逐帧降混成单声道写入有界环形缓冲。
- `loud`：输出设备按**自身默认格式**播放，每输出一帧从缓冲拉取一个单声道样本（采样率不同时线性重采样），再复制到所有输出声道。
- 缓冲保留约 **50ms 播放余量**，并设了上限，既避免贴边抽空产生断续，也避免生产者过快导致延迟和内存无限增长（想改延迟可在 `src/lib.rs` 的 `AudioBus::init` 中调整 `0.05`）。

## 运行模式

程序通过 `-d <mode>` 参数选择运行模式（会同时要求系统存在默认输入与默认输出设备）：

| 模式 | 含义 | 现状 |
| --- | --- | --- |
| `0` | 单机扩音：同一台电脑上 mic → 扬声器 | ✅ 可用，主要用法 |
| `1` | 服务端模式：采集麦克风 + 启动 WebSocket 服务 | ⚠️ 开发中 |
| `2` | 客户端模式：本地放声 + 连接 WebSocket 服务端 | ⚠️ 开发中 |

> ⚠️ **模式 1 / 2 目前尚未真正传输麦克风音频**：当前 server/client 只是把标准输入输出在 WebSocket 之间转发（原“把采集音频发给服务端”的代码已被移除）。若目标是“A 机采麦、B 机放声”的局域网方案，这部分仍待实现。

## 环境要求

- Rust（edition 2021）
- 系统存在默认麦克风与默认扬声器（模式无关，启动时都会探测，找不到会直接报错退出）
- 主要在 Windows（cpal WASAPI）上验证；其他平台取决于 cpal 后端支持情况

## 构建与运行

```bash
cargo build --release

# 单机扩音（对着麦克风说话，从扬声器实时放出）
cargo run --release -- -d 0
```

也可直接运行生成的二进制：

```bash
./target/release/loud-speaker.exe -d 0
```

## 注意事项

- 扩音即“麦 → 箱”实时回放，麦克风对着扬声器会形成**啸叫/回授**，请调整方向与音量。
- 播放起点约有一小段（~50ms 余量对应的）静音缓冲，属正常现象。
- 默认扩音存在约数十毫秒延迟，如需更小延迟，可调小 `src/lib.rs` 中的播放余量系数。
